# Julian Carvalho — Landing Page Designer

Portfolio concept for the CloudWalk Landing Page Designer application.

## Included work

- **CloudPay** — fintech acquisition page focused on clarity and conversion.
- **Signal** — AI productivity launch focused on trust and differentiation.
- **Atlas** — modular campaign system focused on scale and consistency.

All three are original concept projects, clearly presented as concepts rather than client work. The page is a static, responsive site with no build step required.

## AI-first process shown

The portfolio explains a workflow where AI expands exploration and speeds up prototyping, while creative direction, accessibility, interaction quality and final judgment remain design-led.
